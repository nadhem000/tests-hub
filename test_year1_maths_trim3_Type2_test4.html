Correction détaillée – analyse et développement

Algèbre - Exercice 1

a) Résolution du système :

\(\begin{cases} 3x - y - 11 = 0 & (1) \\ x + 2y + 9 = 0 & (2) \end{cases}\)

De (1) : \(y = 3x - 11\). On substitue dans (2) :

\(x + 2(3x - 11) + 9 = 0 \Rightarrow x + 6x - 22 + 9 = 0 \Rightarrow 7x - 13 = 0 \Rightarrow x = \dfrac{13}{7}\).

Puis \(y = 3 \times \dfrac{13}{7} - 11 = \dfrac{39}{7} - \dfrac{77}{7} = -\dfrac{38}{7}\).

Solution : \(S = \left\{\left(\dfrac{13}{7}\,;\,-\dfrac{38}{7}\right)\right\}\).

b) Systèmes avec valeurs absolues :

(S₁) : On pose \(u = |x| \ge 0\). Le système devient \(\begin{cases} 3u - y - 11 = 0 \\ u + 2y + 9 = 0 \end{cases}\).

C'est exactement le système précédent avec \(u\) à la place de \(x\). Donc \(u = \dfrac{13}{7}\) et \(y = -\dfrac{38}{7}\).

\(u = |x| = \dfrac{13}{7} \Rightarrow x = \dfrac{13}{7}\) ou \(x = -\dfrac{13}{7}\).

\(S_1 = \left\{\left(\dfrac{13}{7}\,;\,-\dfrac{38}{7}\right),\ \left(-\dfrac{13}{7}\,;\,-\dfrac{38}{7}\right)\right\}\).

(S₂) : On pose \(v = |y| \ge 0\). Le système devient \(\begin{cases} 3x - v - 11 = 0 \\ x + 2v + 9 = 0 \end{cases}\).

De la première : \(v = 3x - 11\). Dans la seconde : \(x + 2(3x - 11) + 9 = 0 \Rightarrow 7x - 13 = 0 \Rightarrow x = \dfrac{13}{7}\).

Alors \(v = 3 \times \dfrac{13}{7} - 11 = \dfrac{39}{7} - \dfrac{77}{7} = -\dfrac{38}{7}\).

Or \(v = |y| \ge 0\) et \(-\dfrac{38}{7} < 0\) : impossible.

\(S_2 = \varnothing\) (aucune solution).

Algèbre - Exercice 2

1) Encadrements : On sait que \(-2 < x < 1\).

\(a = x + 3\) : \(-2 + 3 < x + 3 < 1 + 3 \Rightarrow \mathbf{1 < a < 4}\).

\(b = \dfrac{3}{x+3} = \dfrac{3}{a}\). La fonction \(t \mapsto \dfrac{3}{t}\) est décroissante sur \(]0;+\infty[\). Comme \(1 < a < 4\), on a :

\(\dfrac{3}{4} < b < 3\), soit \(\mathbf{0{,}75 < b < 3}\).

2)a) Transformation de \(y\) :

\(y = \dfrac{2x+3}{x+3} = \dfrac{2x+6-3}{x+3} = \dfrac{2(x+3)-3}{x+3} = 2 - \dfrac{3}{x+3} = 2 - b\). CQFD.

2)b) Encadrement de \(y\) :

\(y = 2 - b\) avec \(\dfrac{3}{4} < b < 3\).

\(2 - 3 < 2 - b < 2 - \dfrac{3}{4} \Rightarrow \mathbf{-1 < y < \dfrac{5}{4}}\).

Algèbre - Exercice 3

a) \((2x+1) + \dfrac{x-1}{2} < x + \dfrac{1}{3}\)

\(\dfrac{4x+2}{2} + \dfrac{x-1}{2} < \dfrac{3x}{3} + \dfrac{1}{3}\) — mettons tout au même dénominateur 6 :

\(\dfrac{3(4x+2) + 3(x-1)}{6} < \dfrac{2(3x) + 2}{6}\)

\(12x+6 + 3x-3 < 6x+2 \Rightarrow 15x+3 < 6x+2 \Rightarrow 9x < -1 \Rightarrow x < -\dfrac{1}{9}\).

\(S_a = \left]-\infty\,;\,-\dfrac{1}{9}\right[\).

b) \((3x+1)(-2x+4) + (2x-4)(x-5) \le 0\)

Factorisons : \((3x+1)(-2x+4) + (2x-4)(x-5) = -2(3x+1)(x-2) + 2(x-2)(x-5)\)

\(= 2(x-2)\big[-(3x+1) + (x-5)\big] = 2(x-2)(-2x-6) = -4(x-2)(x+3)\).

L'inéquation \(-4(x-2)(x+3) \le 0\) équivaut à \((x-2)(x+3) \ge 0\).

Tableau de signes : positif à l'extérieur des racines \(-3\) et \(2\).

\(S_b = \left]-\infty\,;\,-3\right] \cup \left[2\,;\,+\infty\right[\).

c) \(|3x+6| + 2x + 3 = 0\)

Cas 1 : \(3x+6 \ge 0 \Leftrightarrow x \ge -2\). L'équation devient \(3x+6+2x+3=0 \Rightarrow 5x+9=0 \Rightarrow x=-\dfrac{9}{5}\).

Vérification : \(-\dfrac{9}{5} = -1{,}8 \ge -2\) ✓.

Cas 2 : \(3x+6 < 0 \Leftrightarrow x < -2\). L'équation devient \(-(3x+6)+2x+3=0 \Rightarrow -x-3=0 \Rightarrow x=-3\).

Vérification : \(-3 < -2\) ✓.

\(S_c = \left\{-3\,;\,-\dfrac{9}{5}\right\}\).

Géométrie - Exercice 1

1) Angle \(\widehat{C}\) : \(\widehat{C} = 180^\circ - \widehat{A} - \widehat{B} = 180^\circ - 45^\circ - 60^\circ = \mathbf{75^\circ}\).

Construction : tracer \(BC = 6\text{ cm}\). En \(B\), construire un angle de \(60^\circ\) ; en \(C\), un angle de \(75^\circ\) du côté opposé. L'intersection donne \(A\).

2) Cercle circonscrit :

a) Le centre \(O\) est l'intersection des médiatrices de \([BC]\) et \([AB]\) (ou \([AC]\)).

b) \((OC)\) est un rayon ; \(C'\) est diamétralement opposé à \(C\), donc \([CC']\) est un diamètre.

\(\widehat{CC'B}\) est un angle inscrit interceptant l'arc \(\overset{\frown}{CB}\). L'angle au centre \(\widehat{COB} = 2\widehat{A} = 90^\circ\). Donc \(\widehat{CC'B} = \dfrac{1}{2}\widehat{COB} = \mathbf{45^\circ}\).

Loi des sinus : \(\dfrac{BC}{\sin\widehat{A}} = 2R \Rightarrow \dfrac{6}{\sin 45^\circ} = \dfrac{6}{\sqrt{2}/2} = \dfrac{12}{\sqrt{2}} = 6\sqrt{2}\).

Donc \(R = 3\sqrt{2}\text{ cm}\) et \(CC' = 2R = \mathbf{6\sqrt{2}\text{ cm}}\).

3) Angle \(\widehat{ACC'}\) : \(\widehat{ACC'}\) intercepte l'arc \(\overset{\frown}{AC'}\). L'angle au centre \(\widehat{AOC'} = 2\widehat{B} = 120^\circ\). Donc \(\widehat{ACC'} = \dfrac{1}{2} \times 120^\circ = \mathbf{60^\circ}\).

Dans le triangle \(ACC'\), \([CC']\) est un diamètre donc \(\widehat{CAC'} = 90^\circ\).

\(\sin\widehat{ACC'} = \dfrac{AC}{CC'} \Rightarrow AC = CC' \times \sin 60^\circ = 6\sqrt{2} \times \dfrac{\sqrt{3}}{2} = \mathbf{3\sqrt{6}\text{ cm}}\).

4) Projeté orthogonal \(H\) :

Dans le triangle \(BCH\) rectangle en \(H\) : \(\widehat{B} = 60^\circ\), donc \(BH = BC \cos 60^\circ = 6 \times \dfrac{1}{2} = \mathbf{3\text{ cm}}\).

\(CH = BC \sin 60^\circ = 6 \times \dfrac{\sqrt{3}}{2} = 3\sqrt{3}\text{ cm}\).

Dans le triangle \(ACH\) rectangle en \(H\) : \(\widehat{A} = 45^\circ\), donc \(AH = \dfrac{CH}{\tan 45^\circ} = CH = 3\sqrt{3}\text{ cm}\).

Vérification : \(AC = \dfrac{CH}{\sin 45^\circ} = \dfrac{3\sqrt{3}}{\sqrt{2}/2} = 3\sqrt{6}\text{ cm}\) (cohérent).

\(AB = AH + HB = 3\sqrt{3} + 3 = \mathbf{3(\sqrt{3}+1)\text{ cm}}\).

Géométrie - Exercice 2

1) \(IJKL\) est un parallélogramme :

Dans le triangle \(ACD\), \(I\) et \(J\) sont les milieux de \([AC]\) et \([AD]\). Donc \(IJ \parallel CD\) et \(IJ = \dfrac{1}{2}CD\).

Dans le triangle \(BCD\), \(L\) et \(K\) sont les milieux de \([BC]\) et \([BD]\). Donc \(LK \parallel CD\) et \(LK = \dfrac{1}{2}CD\).

Ainsi \(IJ \parallel LK\) et \(IJ = LK\). De même, \(IL \parallel AB\) et \(JK \parallel AB\) avec \(IL = JK = \dfrac{1}{2}AB\).

Le quadrilatère \(IJKL\) a ses côtés opposés parallèles et égaux : c'est un parallélogramme.

2) \((DC) \perp (AOB)\) :

\(AD = AC\) donc le triangle \(ADC\) est isocèle en \(A\). \(O\) étant le milieu de \([DC]\), la médiane \((AO)\) est aussi hauteur : \(AO \perp DC\).

\(BD = BC\) donc le triangle \(BDC\) est isocèle en \(B\). De même, \(BO \perp DC\).

La droite \((DC)\) est orthogonale à deux droites sécantes \((AO)\) et \((BO)\) du plan \((AOB)\). Donc \((DC) \perp (AOB)\).

3)a) \((OH) \perp (DC)\) :

\(H \in (AB)\) et \(O \in (AOB)\), donc \((OH) \subset (AOB)\). Comme \((DC) \perp (AOB)\), toute droite du plan \((AOB)\) est orthogonale à \((DC)\). En particulier, \((OH) \perp (DC)\).

3)b) \((OH) \perp (IJKL)\) :

On a montré que \(IJ \parallel LK \parallel CD\) et \(IL \parallel JK \parallel AB\).

Par construction, \(H\) est le projeté orthogonal de \(O\) sur \((AB)\), donc \(OH \perp AB\). Ainsi \(OH\) est perpendiculaire à \(AB\), donc à \(IL\) et \(JK\) (parallèles à \(AB\)).

De plus, d'après 3)a), \(OH \perp DC\), donc \(OH \perp IJ\) et \(OH \perp LK\) (parallèles à \(CD\)).

\((OH)\) est orthogonale à deux directions non parallèles du plan \((IJKL)\) (celles de \(AB\) et de \(CD\)). Donc \((OH) \perp (IJKL)\).
