Exercice 1

1) Résolution du système :

\(\begin{cases} x - y = -11 \quad (1) \\ 5x + 3y = 81 \quad (2) \end{cases}\)

De l'équation (1) on exprime \(y\) en fonction de \(x\) : \(y = x + 11\).

On substitue dans (2) : \(5x + 3(x + 11) = 81\) ⇒ \(5x + 3x + 33 = 81\) ⇒ \(8x = 48\) ⇒ \(x = 6\).

Puis \(y = 6 + 11 = 17\).

Solution : \(x = 6,\ y = 17\).

2)a) Moyenne :

\(\bar{X} = \dfrac{5\times a + 1\times 9 + 2\times 10 + 4\times 13 + 3\times b}{5+1+2+4+3}\)

\(\bar{X} = \dfrac{5a + 9 + 20 + 52 + 3b}{15} = \dfrac{5a + 3b + 81}{15}\). CQFD.

2)b) Détermination de a et b :

On donne \(\bar{X} = 10,8\) donc \(\dfrac{5a + 3b + 81}{15} = 10,8\) ⇒ \(5a + 3b + 81 = 162\) ⇒ \(5a + 3b = 81\).

Étendue = 11. Les valeurs sont classées dans l'ordre croissant : a, 9, 10, 13, b. Donc \(b - a = 11\).

On résout le système \(\begin{cases} 5a + 3b = 81 \\ b = a + 11 \end{cases}\).

Substitution : \(5a + 3(a+11) = 81\) ⇒ \(8a + 33 = 81\) ⇒ \(8a = 48\) ⇒ \(a = 6\).

Alors \(b = 6 + 11 = 17\).

Exercice 3

1)a) Voir figure.

1)b) Composantes des vecteurs :
\(\overrightarrow{AC} = (4-3,\ 1-4) = (1,-3)\)
\(\overrightarrow{AN} = (5-3,\ -2-4) = (2,-6)\).

1)c) Milieu : On remarque que \(\overrightarrow{AN} = 2\times\overrightarrow{AC}\). Les vecteurs sont colinéaires donc A, C, N alignés et \(AC = \frac12 AN\). Ainsi C est le milieu de \([AN]\). Vérification par les coordonnées : \(\frac{3+5}{2}=4\), \(\frac{4+(-2)}{2}=1\), ce sont bien celles de C.

2)a) Triangle rectangle isocèle :
\(AB^2 = (0-3)^2 + (3-4)^2 = (-3)^2+(-1)^2 = 10\)
\(AC^2 = (1)^2+(-3)^2 = 10\)
\(BC^2 = (4-0)^2+(1-3)^2 = 16+4 = 20\).
On a \(AB^2 = AC^2\) donc \(AB = AC\) : triangle isocèle en A.
De plus \(AB^2 + AC^2 = 10+10 = 20 = BC^2\) : d'après la réciproque du théorème de Pythagore, le triangle est rectangle en A.
ABC est rectangle isocèle en A.

2)b) Coordonnées de D pour que ABCD soit un carré :
Puisque ABC est rectangle isocèle en A, le point D est tel que \(\overrightarrow{AD} = \overrightarrow{BC}\).
\(\overrightarrow{BC} = (4-0,\ 1-3) = (4,-2)\)
Donc \(D = A + \overrightarrow{BC} = (3+4,\ 4-2) = (7,2)\).

3) Rotation de centre A, quart de tour indirect : Une rotation de -90° (indirect) autour de A transforme un vecteur \((x,y)\) en \((y,-x)\).

3)a) \(R(A) = A\).
Pour C : \(\overrightarrow{AC} = (1,-3)\). Son image par la rotation est \((y,-x) = (-3,-1)\).
Donc \(R(C) = A + (-3,-1) = (3-3,\ 4-1) = (0,3)\) qui est le point B.

3)b) Image de N : \(\overrightarrow{AN} = (2,-6)\). Image = \((y,-x) = (-6,-2)\).
\(N' = (3-6,\ 4-2) = (-3,2)\).

3)c) B milieu de [AN'] : Milieu de \([AN'] = \left(\frac{3+(-3)}{2},\ \frac{4+2}{2}\right) = (0,3) = B\). CQFD.
Construction de \(B' = R(B)\) : \(\overrightarrow{AB} = (-3,-1)\), image par rotation = \((y,-x) = (-1,3)\).
Donc \(B' = (3-1,\ 4+3) = (2,7)\).

Exercice 4

1) Nature de la base réduite : La réduction conserve la forme, donc \(A'B'C'D'\) est un rectangle (réduction d'un rectangle).

2) Calcul de SO : Le volume d'une pyramide est \(V = \frac13 \times \text{aire}_{\text{base}} \times \text{hauteur}\).
Ici \(V = 70\text{ cm}^3\) et aire de base = \(30\text{ cm}^2\).
On a \(70 = \frac13 \times 30 \times SO\) ⇒ \(70 = 10 \times SO\) ⇒ \(SO = 7\text{ cm}\).

3) Volume de la pyramide réduite : Le rapport de réduction est \(k = \frac{SO'}{SO} = \frac23\).
Pour les volumes, on multiplie par \(k^3\) : \(V' = k^3 \times V = \left(\frac23\right)^3 \times 70 = \frac{8}{27} \times 70 = \frac{560}{27} \approx 20,74\text{ cm}^3\).

4) Aire de la base réduite : Pour les aires, on multiplie par \(k^2\) :
\(A' = k^2 \times 30 = \left(\frac23\right)^2 \times 30 = \frac{4}{9} \times 30 = \frac{120}{9} = \frac{40}{3} \approx 13,33\text{ cm}^2\).
