Chimie – Exercice 1 (Équilibrer des équations chimiques)

a) H2S + O2 → H2O + S

  1. On compte les atomes :
    Réactifs : H = 2, S = 1, O = 2
    Produits : H = 2, S = 1, O = 1
  2. Le soufre et l’hydrogène sont déjà équilibrés. L’oxygène est en excès à gauche (2 contre 1).
  3. On multiplie H2O par 2 pour obtenir 2 O à droite :
    H2S + O2 → 2 H2O + S
    Maintenant H à droite vaut 4, donc on doit multiplier H2S par 2 : 2 H2S + O2 → 2 H2O + S.
  4. Pour le soufre : maintenant 2 S à gauche, 1 S à droite → on multiplie S par 2.
    Équation finale : 2 H2S + O2 → 2 H2O + 2 S

b) N2 + O2 → NO2

  1. Réactifs : N = 2, O = 2 ; Produit : N = 1, O = 2.
  2. On équilibre l’azote en mettant 2 NO2 : N2 + O2 → 2 NO2.
    L’oxygène à droite passe à 2×2 = 4, alors qu’à gauche il est de 2.
  3. On multiplie O2 par 2 : N2 + 2 O2 → 2 NO2. Vérification : N = 2↔2 ; O = 2×2 = 4↔4.

c) CO + Fe3O4 → CO2 + Fe

  1. Fer : 3 à gauche, 1 à droite → on multiplie Fe par 3 :
    CO + Fe3O4 → CO2 + 3 Fe
  2. Oxygène : à gauche : 1 (de CO) + 4 (de Fe3O4) = 5 ; à droite : 2 (de CO2). Déséquilibre.
  3. On pose 𝑎 CO et 𝑏 CO2 avec conservation du carbone : 𝑎 = 𝑏.
    Bilan oxygène : 𝑎 + 4 = 2𝑏 ⇒ 𝑎 + 4 = 2𝑎 ⇒ 𝑎 = 4.
  4. Equation : 4 CO + Fe3O4 → 4 CO2 + 3 Fe. Vérification : C = 4↔4 ; O = 4+4 = 8↔8 ; Fe = 3↔3.

d) CaO + C → CaC2 + CO

  1. Calcium : 1↔1 (OK). Oxygène : 1↔1 (OK). Carbone : gauche 1, droite 2 + 1 = 3.
  2. On multiplie le carbone à gauche par 3 : CaO + 3 C → CaC2 + CO.
    Vérification : Ca = 1↔1 ; O = 1↔1 ; C = 3↔3.

Chimie – Exercice 2 (Combustion du magnésium)

1)a) Montrer qu’il s’agit d’une réaction chimique

Étape 1 : Le composé A brûle dans le dioxygène, les réactifs disparaissent.
Étape 2 : Un nouveau corps apparaît : l’oxyde de magnésium MgO, de nature différente des réactifs.
Conclusion : Il y a une transformation chimique car la composition de la matière change.

1)b) Nature de la réaction

La réaction ne débute qu’après chauffage (amorçage). Elle se poursuit ensuite avec un vif éclat, très rapidement. Il s’agit d’une réaction amorcée et rapide.

1)c) Identification du composé A

D’après la loi de conservation des éléments (Lavoisier), le produit MgO contient Mg et O. Le dioxygène apporte O, donc le composé A doit contenir Mg. Il s’agit du magnésium Mg.

2)a) Équation de la réaction

Réactifs : Mg(s) + O2(g)
Produit : MgO(s)
Équation provisoire : Mg + O2 → MgO
Équilibrage : O : 2 ↔ 1 → on double MgO : Mg + O2 → 2 MgO ; Mg devient 1 ↔ 2 → on double Mg.
2 Mg + O2 → 2 MgO

2)b) Montrer que les deux réactifs sont limitants

Quantités de matière initiales :
\(n_{\text{Mg}} = \dfrac{m_1}{M(\text{Mg})} = \dfrac{4,8\ \text{g}}{24\ \text{g·mol}^{-1}} = 0,20\ \text{mol}\)
\(n_{\text{O}_2} = \dfrac{V_2}{V_M} = \dfrac{2,4\ \text{L}}{24\ \text{L·mol}^{-1}} = 0,10\ \text{mol}\)

L’équation donne un rapport stœchiométrique \( \dfrac{n_{\text{Mg}}}{n_{\text{O}_2}} = 2\).
Rapport réel : \( \dfrac{0,20}{0,10} = 2\) → proportions exactes. Les deux réactifs disparaîtront totalement, ils sont tous les deux limitants.

2)c) Masse d’oxyde de magnésium formée (deux méthodes)

\(M(\text{MgO}) = 24 + 16 = 40\ \text{g·mol}^{-1}\).

Méthode 1 (quantité de matière) :
\( n_{\text{MgO}} = n_{\text{Mg}} = 0,20\ \text{mol}\)
\( m = 0,20 \times 40 = 8,0\ \text{g}\).

Méthode 2 (conservation de la masse) :
Masse de O2 : \( m_{\text{O}_2} = 0,10 \times 32 = 3,2\ \text{g}\)
Masse totale des réactifs = 4,8 + 3,2 = 8,0 g → masse des produits = 8,0 g.
m = 8,0 g.

Physique – Exercice 1 (Lampe suspendue)

1) Forces exercées sur la lampe

  • \(\vec{P}\) : poids de la lampe, action de la Terre, verticale vers le bas.
  • \(\vec{T}\) : tension du câble, action du câble sur la lampe, verticale vers le haut.

2)a) Caractéristiques du poids

  • Direction : verticale du lieu.
  • Sens : vers le bas.
  • Point d’application : centre de gravité G de la lampe.
  • Valeur : \(P = 25\ \text{N}\).

2)b) Condition d’équilibre

La lampe est immobile, donc d’après le principe d’inertie : \(\vec{P} + \vec{T} = \vec{0}\).
Cela implique que \(\vec{T}\) a la même direction, un sens opposé et la même norme que \(\vec{P}\), donc \(T = P = 25\ \text{N}\).

2)c) Représentation à l’échelle

Échelle : 1 cm ↔ 12,5 N. Les deux forces valent donc 2 cm. La figure ci‑dessous les montre appliquées en G (point orange).

3) Poids sur la Lune

La masse de la lampe est constante (\(m = \frac{P}{g} = \frac{25}{10} = 2,5\ \text{kg}\)).
Le poids \(P = m\,g\) dépend de l’intensité de la pesanteur \(g\). Sur la Lune, \(g \approx 1,6\ \text{N·kg}^{-1}\), environ 6 fois plus faible que sur Terre, d’où un poids de \(2,5 \times 1,6 \approx 4\ \text{N}\).

Physique – Exercice 2 (Ressort et masse)

1) Forces sur le solide S

  • \(\vec{P}\) : poids, vertical vers le bas, \(P = m\,g = 0,5 \times 10 = 5\ \text{N}\).
  • \(\vec{T}\) : tension du ressort, verticale vers le haut.

2)a) Allongement du ressort

\(\Delta L = L - L_0 = 27,5\ \text{cm} - 25\ \text{cm} = 2,5\ \text{cm} = 2,5 \times 10^{-2}\ \text{m}\).

2)b) Démonstration de \(k = \dfrac{m\,g}{\Delta L}\)

À l’équilibre : \(\vec{P} + \vec{T} = \vec{0}\) → \(T = P\).
Loi de Hooke : \(T = k\,\Delta L\).
D’où \(k\,\Delta L = m\,g\) → \(k = \dfrac{m\,g}{\Delta L}\).

2)c) Valeur de \(k\)

\(k = \dfrac{0,5 \times 10}{2,5 \times 10^{-2}} = \dfrac{5}{0,025} = 200\ \text{N·m}^{-1}\).

3)a) Nouvel allongement avec \(k' = 1000\ \text{N·m}^{-1}\)

\(\Delta L' = \dfrac{m\,g}{k'} = \dfrac{5}{1000} = 0,005\ \text{m} = 0,5\ \text{cm}\).

3)b) Nouvelle longueur du ressort

\(L' = L_0 + \Delta L' = 25 + 0,5 = 25,5\ \text{cm}\).
