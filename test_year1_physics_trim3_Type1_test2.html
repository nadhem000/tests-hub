Chimie – Exercice 1 : Nitrate de potassium (KNO₃)

1) Masse molaire moléculaire
Règle : la masse molaire moléculaire est la somme des masses molaires atomiques de chaque atome contenu dans la molécule.
\(M(K) = 39\ \mathrm{g·mol}^{-1}\), \(M(N) = 14\ \mathrm{g·mol}^{-1}\), \(M(O) = 16\ \mathrm{g·mol}^{-1}\).
Pour \(KNO_3\) : \(M = 39 + 14 + 3 \times 16 = 39 + 14 + 48 = 101\ \mathrm{g·mol}^{-1}\).

2) Solution S
a) Règle : le soluté est l'espèce dissoute, le solvant le liquide majoritaire.
Soluté = nitrate de potassium, solvant = eau.
b) Solution aqueuse de nitrate de potassium.
c) Concentration massique \(C_m\) : \(C_m = \dfrac{m_{\text{soluté}}}{V_{\text{solution}}}\). \(V = 500\ \mathrm{mL} = 0,500\ \mathrm{L}\).
\(C_m = \dfrac{15,2\ \mathrm{g}}{0,500\ \mathrm{L}} = 30,4\ \mathrm{g·L}^{-1}\).
d) Concentration molaire \(C\) : \(C = \dfrac{C_m}{M}\).
\(C = \dfrac{30,4\ \mathrm{g·L}^{-1}}{101\ \mathrm{g·mol}^{-1}} \approx 0,301\ \mathrm{mol·L}^{-1}\).

3) Dilution
a) Masse \(m'_1\) dans 100 mL de S : \(m = C_m \times V'\). \(V' = 100\ \mathrm{mL} = 0,100\ \mathrm{L}\).
\(m'_1 = 30,4 \times 0,100 = 3,04\ \mathrm{g}\).
b) Concentration \(C_1\) : volume total \(150\ \mathrm{mL} = 0,150\ \mathrm{L}\).
\(C_1 = \dfrac{3,04\ \mathrm{g}}{0,150\ \mathrm{L}} \approx 20,27\ \mathrm{g·L}^{-1}\).

4) Ajout de solide
a) \(m'_2\) dans 200 mL : \(30,4 \times 0,200 = 6,08\ \mathrm{g}\).
b) Masse totale dissoute = 6,08 + 1,0 = 7,08 g.
c) \(C_2 = \dfrac{7,08}{0,200} = 35,4\ \mathrm{g·L}^{-1}\).

Chimie – Exercice 2 : Solubilité de l'aspirine

1) Solution non saturée
Règle : masse maximale dissoute = solubilité × volume.
\(m_{\max} = 3,3\ \mathrm{g·L}^{-1} \times 0,100\ \mathrm{L} = 0,33\ \mathrm{g}\).
On a mis 0,25 g < 0,33 g → la solution n'est pas saturée.

2) Solution saturée
a) Pour 50 mL (0,050 L) : \(m_{\max} = 3,3 \times 0,050 = 0,165\ \mathrm{g}\).
Or on a 0,20 g > 0,165 g → solution saturée.
La concentration d'une solution saturée est égale à la solubilité : \(C = 3,3\ \mathrm{g·L}^{-1}\).
b) Masse du dépôt = masse introduite − masse dissoute = \(0,20 - 0,165 = 0,035\ \mathrm{g}\).
