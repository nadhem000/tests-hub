تصحيح الفرض – تحليل مفصّل

التمرين 1 (5 نقاط)

1) الإجابة الصحيحة: ب) قائم في \(B\).

في المكعب، \(O\) مركز الوجه \(ABCD\). المستقيم \((BF)\) عمودي على المستوى \((ABC)\) لأنه حرف جانبي في المكعب. وبالتالي \((BF) \perp (OB)\) لأن \((OB)\) محتوى في \((ABC)\). إذن الزاوية \(\widehat{OBF}\) قائمة في \(B\).

2) الإجابة الصحيحة: ج) \(\varnothing\).

\(x^2 + 4 = 0 \Rightarrow x^2 = -4\). لا يوجد عدد حقيقي مربعه سالب. إذن مجموعة الحلول فارغة: \(S = \varnothing\).

3) الإجابة الصحيحة: ب) خطأ.

بالتعويض: \((-3)^2 - 6(-3) + 9 = 9 + 18 + 9 = 36 \neq 0\). إذن \(-3\) ليس حلاً للمعادلة. (الحل الحقيقي هو \(x=3\) لأن \(x^2-6x+9=(x-3)^2\).)

4) الإجابة الصحيحة: أ) \(2x\).

بما أن \(-1 < x < 1\): فإن \(x+1 > 0\) و \(x-1 < 0\). إذن \(|x+1| = x+1\) و \(|x-1| = -(x-1) = 1-x\).
\(A = (x+1) - (1-x) = x+1-1+x = 2x\).

5) الإجابة الصحيحة: أ) \((SD) \perp (ABC)\).

لدينا \((SD) \perp (AD)\) و \((SD) \perp (DC)\). المستقيمان \((AD)\) و\((DC)\) متقاطعان في \(D\) ويحددان المستوى \((ABC)\) (قاعدة الهرم). إذن \((SD)\) عمودي على مستقيمين غير متوازيين من المستوى \((ABC)\)، فهو عمودي على المستوى بأكمله.

التمرين 2 (4 نقاط)

1) أ) حصر \(x - y\):

لدينا \(-3 \le y \le 5\) و \(-1 < x < 1\).

أصغر قيمة لـ \(x-y\): \(x\) الأصغر \((-1^+)\) ناقص \(y\) الأكبر \((5)\) يعطي \(-6^+\) (أي أكبر من \(-6\) بقليل).

أكبر قيمة: \(x\) الأكبر \((1^-)\) ناقص \(y\) الأصغر \((-3)\) يعطي \(4^-\).

إذن: \(-6 < x - y < 4\).

ب) حصر \(2 - x\):

\(-1 < x < 1 \Rightarrow -1 < -x < 1 \Rightarrow 1 < 2-x < 3\).

إذن: \(1 < 2 - x < 3\).

2) أ) حصر \(xy - y^2 = y(x-y)\):

نحلل: \(y \in [-3, 5]\) و \((x-y) \in (-6, 4)\).

ندرس الإشارات: عندما \(y \ge 0\): \(y(x-y)\) محصور بين \(y \times (-6)\) و \(y \times 4\). عندما \(y < 0\): الضرب يعكس المتراجحة.

بالدراسة المنهجية على المستطيل \([-3,5] \times (-6,4)\): القيمة الدنيا \(-30^+\) (عندما \(y \to 5\) و \(x \to -1^+\))، القيمة القصوى \(20^-\) (عندما \(y \to 5\) و \(x \to 1^-\) لكن هذا غير ممكن لأن \(x-y\) عند \(y=5\) محصور بين \(-6\) و \(-4\) مما يعطي ضرباً بين \(-30\) و \(-20\)).

النتيجة المُحكمة: \(-30 < xy - y^2 < 18\). (الحد الأعلى \(18\) يتحقق عندما \(y=-3\) و \(x-y \to 4^-\) أي \(x \to 1^-\)).

ملاحظة: يمكن للتلميذ تقديم حصر تقريبي مقبول \(-30 < xy-y^2 < 20\) مع تبرير معقول.

ب) حصر \(4x^2 - 2x + 4\):

نكتب \(f(x) = 4x^2 - 2x + 4 = 4\left(x - \frac{1}{4}\right)^2 + \frac{15}{4}\).

على \((-1, 1)\): الحد الأدنى عند \(x = \frac{1}{4}\) حيث \(f = \frac{15}{4} = 3.75\). عند \(x \to -1^+\): \(f \to 4+2+4=10\). عند \(x \to 1^-\): \(f \to 4-2+4=6\).

إذن: \(\frac{15}{4} \le 4x^2 - 2x + 4 < 10\). أي \([3.75\;;\; 10[\).

التمرين 3 (5 نقاط)

1) أ) \(2x - 1 = 3x + 1 \Rightarrow -1 - 1 = 3x - 2x \Rightarrow -2 = x\). إذن \(S = \{-2\}\).

ب) \((5x-1)^2 = 9x^2 \Rightarrow (5x-1)^2 - (3x)^2 = 0 \Rightarrow [(5x-1)-3x][(5x-1)+3x] = 0 \Rightarrow (2x-1)(8x-1) = 0\).

إذن \(2x-1=0\) أي \(x=\frac{1}{2}\)، أو \(8x-1=0\) أي \(x=\frac{1}{8}\). \(S = \left\{\frac{1}{8}; \frac{1}{2}\right\}\).

2) أ) \(A = (x-1)(2x+3) = x(2x+3) - 1(2x+3) = 2x^2 + 3x - 2x - 3 = 2x^2 + x - 3\). ✓

ب) \(A = 0 \Leftrightarrow (x-1)(2x+3) = 0 \Leftrightarrow x-1=0 \text{ أو } 2x+3=0 \Leftrightarrow x=1 \text{ أو } x=-\frac{3}{2}\). \(S = \left\{-\frac{3}{2}; 1\right\}\).

ج) \(A = -3 \Leftrightarrow 2x^2 + x - 3 = -3 \Leftrightarrow 2x^2 + x = 0 \Leftrightarrow x(2x+1) = 0 \Leftrightarrow x=0 \text{ أو } x=-\frac{1}{2}\). \(S = \left\{-\frac{1}{2}; 0\right\}\).

التمرين 4 (6 نقاط)

1) أ) في المكعب، \((CG)\) حرف جانبي. \((CG) \perp (BC)\) و \((CG) \perp (CD)\) لأن الوجوه مربعات. \((BC)\) و\((CD)\) متقاطعان في \(C\) ويحددان المستوى \((ABC)\). إذن \((CG) \perp (ABC)\).

ب) بما أن \((CG) \perp (ABC)\)، فإن \((CG)\) عمودي على كل مستقيم من \((ABC)\) يمر من \(C\)، وخاصة \((AC)\). إذن \((CG) \perp (AC)\) والمثلث \(ACG\) قائم في \(C\).

2) أ) \(AC\) قطر المربع \(ABCD\): \(AC = AB\sqrt{2} = 5\sqrt{2}\).

ب) في المثلث \(ACG\) القائم في \(C\): \(AG^2 = AC^2 + CG^2 = (5\sqrt{2})^2 + 5^2 = 50 + 25 = 75\). إذن \(AG = \sqrt{75} = 5\sqrt{3}\).

3) أ) \(N\) المسقط العمودي لـ \(M\) على \((AC)\) يعني \((MN) \perp (AC)\). وقد بيّنا أن \((CG) \perp (AC)\). في المستوي \((ACG)\)، المستقيمان \((MN)\) و\((CG)\) عموديان على نفس المستقيم \((AC)\)، إذن \((MN) \parallel (CG)\).

ب) في المثلث \(ACG\): \(M \in [AG]\)، \(N \in [AC]\)، و \((MN) \parallel (CG)\). حسب مبرهنة طالس: \(\frac{MN}{CG} = \frac{AM}{AG}\).

\(MN = CG \times \frac{AM}{AG} = 5 \times \frac{3}{5\sqrt{3}} = \frac{3}{\sqrt{3}} = \sqrt{3}\).

ملاحظة: تُبسط \(\frac{3}{\sqrt{3}}\) بضرب البسط والمقام في \(\sqrt{3}\): \(\frac{3\sqrt{3}}{3} = \sqrt{3}\).

4) حساب \(IJ\) حيث \(I\) منتصف \([MG]\) و \(J\) منتصف \([NC]\).

نعتمد نظام إحداثيات: \(A(0,0,0)\)، \(B(5,0,0)\)، \(C(5,5,0)\)، \(D(0,5,0)\)، \(E(0,0,5)\)، \(F(5,0,5)\)، \(G(5,5,5)\)، \(H(0,5,5)\).

\(AG = (5,5,5)\). \(M\) على \([AG]\) حيث \(AM = 3\): \(M = A + \frac{3}{5\sqrt{3}}(5,5,5) = (\sqrt{3}, \sqrt{3}, \sqrt{3})\).

\(N\) مسقط \(M\) على \((AC)\): \(AC = (5,5,0)\). \(N = \frac{M \cdot AC}{|AC|^2} AC = \frac{5\sqrt{3}+5\sqrt{3}+0}{50}(5,5,0) = (\sqrt{3}, \sqrt{3}, 0)\).

\(I = \frac{M+G}{2} = \left(\frac{5+\sqrt{3}}{2}, \frac{5+\sqrt{3}}{2}, \frac{5+\sqrt{3}}{2}\right)\).

\(J = \frac{N+C}{2} = \left(\frac{5+\sqrt{3}}{2}, \frac{5+\sqrt{3}}{2}, 0\right)\).

\(IJ = |J - I| = \left| \left(0, 0, -\frac{5+\sqrt{3}}{2}\right) \right| = \frac{5+\sqrt{3}}{2}\).

تحليل هندسي: \(IJ\) هو متوسط في شبه منحرف \(MGCN\) حيث القاعدتان متوازيتان. يمكن أيضاً استخدام مبرهنة midsegment في الفضاء.
